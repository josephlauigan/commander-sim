--- Reading it ---
  Speed: how fast the deck does the thing it is built to do.
    worse  - Games where the game plan came online (conservative profile only)
  Card flow: how many resources the deck sees; more cards seen means more options and fewer dead draws.
    better - Cards drawn per game (incl. draw step) (conservative profile only)
    better - Tutors resolved per game (both profiles)
  Interaction: how often the deck answers what opponents do.
    worse  - Counterspells cast (loose profile only)
    worse  - Spot removal cast (both profiles)
  Resilience: how well the plan survives opposing interaction.
    worse  - Your key permanents removed by opponents (loose profile only)
    worse  - Your spells countered (both profiles)
  Threat & pressure: how much the deck pushes the game toward a win.
    worse  - Damage dealt to opponents per game (loose profile only)
    worse  -   ...of which combat damage (loose profile only)
  With ~40 checks per run, one or two stars can appear by chance; trust the ones that show
  up under both profiles, or that line up with the card's job.
  Note: per-game counts rise with game length, so check 'Rounds survived' before reading
  more cards drawn or more spells cast as a pure gain.
