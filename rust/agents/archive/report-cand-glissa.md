## AI plan
Bites/fights target the biggest threat some creature kills, using a deathtouch creature first, else the most powerful; not
spent on targets worth < 1.2. Ramp then threats are the generic priorities. Darksteel Plate is equipped to Glissa first
(`plate_options`, utility 4.5); Champion's Helm goes to the best legend (extended `yshtola::helm` to the glissa key).
Glissa's own trigger draws a card by default (the DSL mode valuation; tested), destroys an enchantment only when worth more.
