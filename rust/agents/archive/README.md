# Archived agent files

The briefs, handoffs, reports and scratch files of agent tasks that are finished: each task's brief (`<task>.md`), its
handoff (`handoff-<task>.md`) and its report (`report-<task>.md`), plus the lists and outputs they used. They are kept
as a record; git history (`git log --follow rust/agents/archive/<file>`) has the context of each, and the files still
in `rust/agents/` are the live ones (the rules, the current handoff, the deck lists, the open engine-needs lists, and
reports that `audit/` or a changelog links to).
